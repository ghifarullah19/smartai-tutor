# Update Steering Workflow

Use this workflow when changing:

- product.md
- structure.md
- tech.md

Before updating:

Analyze:

1. Current rule
2. Reason for change
3. Impact on project

Provide:

- Current state
- Proposed change
- Migration impact

Wait for approval.

After approval:

Update steering files.

Ensure:

- Existing specifications remain consistent.
- No contradiction exists between steering and specs.
